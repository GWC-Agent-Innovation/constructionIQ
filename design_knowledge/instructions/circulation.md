# Compact circulation

Treat a hallway as a route, not a destination or leftover room. First consider
whether living and dining can provide practical public access without a
dedicated hall. Zero dedicated hallway is acceptable when access works.

When a hallway is needed, aim for 5-10% of the footprint in total dedicated
circulation, subject to the existing AI compiler's 15% maximum and 5-6 ft
short-side rule. These are product planning heuristics, not building regulations.
Count every hallway together; splitting one oversized hall into several does
not improve the design. A hallway larger than the living room is a warning to
reconsider the grouping, not a reason to rename the hallway as living space.

Trace entry -> living -> dining/kitchen and entry -> each bedroom. Keep routes
short and avoid using bedrooms, kitchens or attached bathrooms as through-routes.
Leave the shared wall spans required by the current tool instructions for
Python to create doors. Never claim access is validated before compilation.
