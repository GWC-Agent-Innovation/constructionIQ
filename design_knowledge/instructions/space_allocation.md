# Space allocation

Before choosing splits, budget useful area for every required room. Use the
current catalog minima and specification caps, not dimensions copied from an
example. Give living and dining purposeful usable space; keep bathrooms and
parking compact. Balance comparable bedrooms unless the user requests a larger
master bedroom. Do not stretch service rooms or circulation to absorb leftovers.

Estimate the area and aspect ratio of each leaf from its parent dimensions.
If a split creates a large unused zone, change the grouping or split direction.
Avoid narrow living rooms and bedrooms whose proportions make basic furniture
placement implausible. Furniture fit is a design consideration, not a verified
clearance result in this application.

All catalog rooms must remain present exactly once. The current compiler fully
tiles a rectangular footprint: do not invent gardens, courtyards or extra rooms
unless the supported catalog explicitly includes them. If the grouping cannot
produce a sensible plan, propose a different grouping or return no proposal.
